# Rough Out redesign brief

Design read: a cinematic creative-studio portfolio for directors, producers, and brands that want a strong visual point of view.

Concept spine: the archive is a working reel, moving from a single chrome studio image into a clear library of finished frames.

Delivery tier: editorial. The user requested no hero video now, so the experience uses static art, restrained movement, and direct interaction.

Animation mode: non-animated - user chose no hero video for this build.

Palette: ink #0d0e10, soft ink #16181b, paper #f2f0ea, chrome grey, and one amber accent #ff9d2e. The palette keeps the original Rough Out dark cinematic mood while making navigation legible.

Type: strong uppercase sans display with a small mono utility layer. The display is direct and production-oriented; mono labels support archive navigation.

Layout: a compact top nav, split hero copy over a static chrome visual, a short capability section, one unified work library, and a focused contact close.

Interaction: smooth anchor navigation, gentle hero image drift, category tabs with project counts, staggered card entry, card hover contrast, and keyboard-visible focus states.

Content: preserve the real Rough Out services, contact details, and project titles from the source portfolio. No fabricated client logos, metrics, reviews, or project claims.

Asset plan: one bespoke chrome studio hero image plus the existing Rough Out project imagery copied into the site asset folder. Hero video intentionally deferred for a later revision.

CTA inventory: hero "View the work" scrolls to the archive; nav "Start a project" scrolls to contact; contact email is the single conversion action.

Mobile: single-column sections, full-width project cards, compact nav, preserved contrast, and reduced-motion fallback.
